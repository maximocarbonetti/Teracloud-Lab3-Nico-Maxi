# Imagenes

## teracloud.png

El estandarte que cuelga de la cola del dragon carga `teracloud.png` desde
esta carpeta.

Pega aca el logo de Teracloud con ese nombre exacto. Recomendado: PNG con
fondo transparente, ~200x90 px.

Si el archivo no existe, el estandarte muestra automaticamente la palabra
"teracloud" en texto, asi que la app no se rompe.
